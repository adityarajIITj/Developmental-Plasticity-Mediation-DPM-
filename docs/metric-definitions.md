# Planned metric definitions

These are metric specifications to finalize before experiments; they are not computed results.

| Metric | Intended question | Definition still required |
|---|---|---|
| Evidence-response contrast | Does the effect of evidence change across mediator settings? | Outcome function, evidence pair, intervention values, estimator |
| Retention | Does learned significance persist after a delay? | Delay, probe, normalization, and comparison condition |
| Extinction | How does significance change under counterevidence or omission? | Extinction schedule, endpoint, and baseline |
| Cross-context transfer | Does a learned effect generalize to a held-out context? | Context split, transfer probe, and success criterion |
| Held-out interventional prediction error | Which model predicts outcomes under unseen interventions? | Loss, aggregation, calibration, and uncertainty |
| Parameter count | How complex is the fitted model? | Counting convention for fixed, learned, and shared parameters |

Finalize these definitions before examining evaluation outcomes. Changing a metric after seeing results must be documented as exploratory rather than silently substituted for the planned analysis.
