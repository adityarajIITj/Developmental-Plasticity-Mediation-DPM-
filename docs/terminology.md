# Terminology

Use these terms consistently in documentation and code comments.

- **History-conditioned mediator (`P`):** The proposed variable that modulates how later evidence updates learned significance.
- **Learned significance (`Z`):** The target construct whose operational measurement remains to be specified for each experiment.
- **Learning evidence (`ε`):** Evidence entering an update rule; it is not assumed to equal a temporal-difference error.
- **Persistence-only account:** A restricted comparator where persistent state changes current inference or action without changing the evidence-to-learning response.
- **Generic meta-learning baseline:** A flexible adaptive controller capable of changing its own learning behavior; it is an important competing explanation.
- **Mediator clamp:** A controlled intervention on the mediator, with timing and off-target paths explicitly defined.
- **Functional affect:** A functional or causal-organizational claim; it does not by itself establish subjective experience.
- **Phenomenal feeling:** A claim about subjective experience, not inferred merely from successful task performance.

Avoid using “validated,” “emotional,” or “conscious” as shorthand for a passing software test.
