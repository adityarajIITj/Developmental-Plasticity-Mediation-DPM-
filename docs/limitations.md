# Current limitations

This repository is an initial native scaffold.

- No DPM update dynamics are implemented.
- No baseline controller is implemented.
- The mediator-clamp intervention is described conceptually but not operationalized in code.
- The draft configuration is not consumed by an experiment runner.
- There are no empirical results.
- The current test covers only the scaffold API.
- The framework does not establish subjective feeling or phenomenal valence.

These limitations should be updated only when corresponding code or evidence exists. Do not infer scientific support from repository completeness, test counts, or build status.
