# Change control for model semantics

Changes to state variables, update equations, intervention definitions, task splits, or primary metrics can alter the scientific question.

When making such a change:

1. Describe the old and new definitions.
2. Explain why the change is needed.
3. Identify which predictions or comparisons are affected.
4. Update the model specification, configuration, tests, and documentation together.
5. Record whether prior results remain comparable.
6. Mark changes motivated by observed evaluation results as post hoc.

Do not preserve a familiar model name across materially different dynamics without documenting the change.
