# Null and negative results

A result that fails to support the DPM-specific prediction is scientifically informative.

Report null or negative findings with the same provenance and protocol detail as positive findings. Distinguish:

- evidence for no practically meaningful difference under a defined margin;
- an estimate too uncertain to distinguish alternatives;
- a failed or underpowered experiment;
- an implementation or protocol failure.

Do not interpret a non-significant result as proof of equivalence without an appropriate equivalence design. Do not omit a baseline or seed because its outcome weakens the preferred explanation.
