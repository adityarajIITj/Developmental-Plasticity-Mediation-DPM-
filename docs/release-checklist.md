# Release readiness checklist

Use this checklist before creating a tagged release.

- [ ] README accurately describes what is implemented.
- [ ] Build instructions have been tested on a clean checkout.
- [ ] CI is green for the release commit.
- [ ] Tests cover the behavior claimed by the release notes.
- [ ] Configuration files are documented and validated.
- [ ] No generated outputs are mistaken for source data or measured results.
- [ ] Known limitations and unsupported behavior are listed.
- [ ] Citation metadata and license are present and consistent.
- [ ] Release notes distinguish code changes from scientific findings.
- [ ] No claim of affect, emotion, or consciousness exceeds the evidence.

A release checklist is a review aid, not evidence that any unchecked item has passed.
