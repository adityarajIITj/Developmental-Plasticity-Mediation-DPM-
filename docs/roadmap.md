# Research roadmap

This roadmap describes dependencies, not promised delivery dates.

## Stage 1 — Scaffold (current)

- Native C++20/CMake build.
- Minimal scaffold test and CI workflow.
- Theory notes, configuration conventions, limitations, and reporting guidance.

## Stage 2 — Specify the experiment

- Formalize state and update equations for each baseline.
- Define mediator interventions and controlled comparisons.
- Fix matching rules, tasks, metrics, seeds, and held-out contexts.

## Stage 3 — Implement and validate

- Implement the minimal reference models.
- Add unit and intervention-invariant tests.
- Validate configuration parsing and result provenance.

## Stage 4 — Evaluate

- Run the preregistered comparison.
- Report uncertainty, null results, and failure cases.
- Assess whether DPM adds explanatory or predictive value beyond strong matched baselines.

No stage beyond the scaffold is represented as complete.
