# Python reference implementation

The `dpm_reference` package is the first executable reference for the operational question in the DPM notes: can an intervention on a history-conditioned mediator change the effect of later evidence on learned significance?

## Included

- `LearnerState`: a scalar significance state.
- `FixedRateLearner`: a fixed-rate comparison update.
- `MediatedLearner`: a toy update whose effective learning rate depends on a mediator intervention.
- `evidence_response_contrast`: computes the difference between next-state outcomes under two evidence values for one fixed mediator setting.

The mediated update is explicitly:

```text
effective_rate = base_rate * (1 + mediator_sensitivity * P)
Z_next = Z + effective_rate * (evidence - Z)
```

Here (P) is constrained to ([0,1]), and the configured maximum effective rate must not exceed one. This update is an illustrative operationalization chosen to make the evidence-response criterion executable; it is not claimed to be the manuscript's uniquely implied equation, a complete DPM theory, or an emotion model.

## Run tests

Install the development dependency and run:

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p 'test_*.py' -v
```

The tests check the update arithmetic, the predicted difference in evidence-response contrasts for the toy mediator settings, and validation of invalid inputs. Passing these tests establishes implementation consistency with the equations above only.

## Known limitations

- Scalar state and evidence only; no environment, actions, belief state, history update, or episode-level mediator dynamics.
- The mediator is externally clamped, not learned or generated by developmental history.
- No generic meta-learning baseline, uncertainty analysis, held-out transfer task, or fitted parameters.
- No empirical comparison or evidence of subjective feeling.
- The draft YAML is not consumed by this package.

The next research step is to specify and implement matched baselines and a task protocol before treating any simulation as evidence for DPM's explanatory value.
