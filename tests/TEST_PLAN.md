# Test plan

This repository currently documents planned validation requirements. The checks below are not implemented tests and must not be described as passing.

## Unit-level checks

- Each model's transition/update rules match its documented equations.
- Random seeds reproduce the same trajectories under deterministic settings.
- Interventions alter only the specified mediator variable (or documented direct descendants).
- Clamps are respected at every step.
- All logged values are finite and metric calculations are unit-tested.

## Experimental invariants

- Model capacity, observations, action opportunities, compute limits, and training/evaluation data are matched according to the preregistered protocol.
- Evaluation contexts are held out and never used for tuning.
- Baseline hyperparameter selection receives a comparable tuning budget.
- Results include uncertainty across seeds and failed runs.
- No reported result is generated by manually filling in an expected outcome.

## Decision rule

The DPM explanatory claim is weakened if the generic meta-learning baseline matches the interventional and transfer outcomes at equal or lower complexity under the preregistered evaluation. Do not equate a positive task score with evidence of subjective feeling.
